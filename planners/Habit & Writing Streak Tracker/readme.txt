Free Printable Resources
========================
Public domain printable PDFs for readers and writers. Brandless, ready to print.

Downloaded from https://github.com/dead0eye/free-printable-resources · GetFreeEbooks.com


WHAT THIS IS
============
Print-ready PDFs: reading journals, book trackers, planners, writing
worksheets, mazes, sudoku, crosswords and mandala colouring pages.

Every file is brandless - no cover, no logo, no header or footer, no
watermark. Print them, sell them, put them in your own book.


WHAT IS IN THIS DOWNLOAD
========================
Each folder holds one category of printable, as PDF.
See README.md in the repository for the current index.

All pages are A4 unless the filename says otherwise. Nothing is watermarked
and nothing carries a logo.
