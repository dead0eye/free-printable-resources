# Contributing

Thanks for considering it. This is a small project and the bar is low: if something is wrong,
say so; if you can fix it, even better.

## The one thing that is not negotiable

**Everything here is CC0.** By opening a pull request you agree that your contribution is
released into the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), with no attribution required
and no rights retained.

That is not a formality. A public domain project stops being public domain the moment one
contribution arrives under different terms, and untangling that later is close to impossible.
If you are not able to release your work this way — because an employer owns it, or because it
is derived from something under a different licence — please do not open the pull request.
Open an issue describing the change instead, and we will write it independently.

**Do not paste in material you did not write** unless you have confirmed it is public domain
or CC0. That includes text generated from a source you cannot licence, and anything copied
from another project. If you are not sure where something came from, leave it out.

## Reporting a problem with a PDF

The useful reports here are specific:

- a page that prints with content cut off at the margin
- a puzzle with no solution, or more than one
- a solution page that does not match its puzzle
- a file that will not open, or opens blank

Include the **filename** and, if you can, which printer or PDF reader you used. A maze that is
unsolvable is a real bug and worth reporting; a maze that is harder than you expected is not.

## Contributing a printable

Open an issue before making anything. These files are generated rather than drawn by hand, so a
one-off PDF is awkward to maintain and will usually be turned down in favour of adding the idea
to a generator.

If you do contribute a file, it has to meet the same bar as everything else here:

- **brandless** — no cover, logo, header, footer, watermark or URL
- **no third-party artwork, clipart or fonts** unless you can show it is public domain or CC0
- **A4**, with a margin that survives a home printer
- **CC0** — you are releasing it into the public domain, which you cannot do with anything you
  did not make yourself

Anything containing material you cannot licence this way cannot be accepted, however good it is.

## Reporting a problem

Open an issue. Useful things to include:

- what you did, what happened, and what you expected instead
- your operating system and browser, if it is relevant
- the exact file or page, if the problem is in one specific place

A vague report is still better than a silent one. We would rather hear it.

## Style

Match what is already there. That is the whole rule. If a file uses two-space indent and short
lines, so does your change.
